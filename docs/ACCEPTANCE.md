# V1.0 运行与验收说明

## 使用

Windows 10/11 64 位，先登录微信 4.1.15.13 并保持运行，然后双击 `Export-WeChat-V1.exe`。
选择微信数据账号目录；启动会自动探测可用目录，可手动浏览账号目录或数据根目录。
默认自动加载最近发现的数据源；存在多账号时请在下拉列表确认。加载后状态栏显示实际账号，后续导出固定使用这个账号。

在左栏按全部/好友/群聊和备注/昵称搜索，点击复选列勾选，空格键可切换；全选仅影响当前筛选结果，取消选择清空全部选择。
右栏选择 TXT/Markdown/JSON、图片/文件和目标目录。只选一种格式时不会隐式写出其他聊天格式。
选择性导出与全部导出都是后台任务，任务进行时不能同时刷新数据源或启动另一任务。

每个任务有单独的 `task-日期-时间-随机后缀` 目录，聊天目录由 username 派生。名称相同的好友、不同任务都不会相互覆盖。
`task_index.json` / `task_index.md` 是任务汇总，记录成功、无消息、失败、取消和消息数。
`INCOMPLETE.txt` 表示任务中断或暂存清理失败；只认可索引里 `exported` 的完整会话。`.partial` 中的文件不属于完整导出。
取消后保留已经成功的会话，删除本次未完成会话；连接或解密中的底层操作需先返回安全检查点，不能瞬间中断。
关闭窗口会先协作取消并等待敏感缓存清理。请勿通过任务管理器强行结束正常任务。

JSON 使用原生聊天预览，每页最多 100 条，区分自己与他人并显示附件状态。
仅 TXT/Markdown 导出使用流式分页文本预览。不会为预览强制生成 JSON；这两种格式的预览不提供内嵌图片按钮，图片/附件保留在会话目录中。

## 核心与完整包

- 核心包：完整保留数据库、图片和普通文件依赖，以及 FFmpeg 和 rust-silk。移出可选的 sherpa-onnx / soundfile 语音识别运行时。
- 完整包：保留原语音识别依赖，旧界面通过 `EXE --legacy` 打开。模型仍不会打进包或自动下载。
- 源码与原 CLI 保留语音/视频功能。V1 默认界面仅提供图片和普通文件，无新增 V2 功能。
- `onedir` ZIP 必须完整解压，不能只拷贝 EXE；默认 `onefile` 可以独立启动。

## 验证边界

本开发环境不使用真实聊天数据库或密钥。自动化验证使用合成 SQLite、图片、附件和 Tk 控件。
通过单元测试和构建不等同于目标微信版本的真实账号兼容验证。
本程序沿用原版读取接口；微信升级、权限差异、数据库变化可能使读取失败。只处理自己有权访问的数据，原数据库只读，无聊天上传。
不需要安装 Python，不需要 Web 服务。不要求关闭 Windows Defender/SmartScreen。

## 待用户真实微信验收

1. Windows 10 / 微信 4.1.15.13：登录后自动探测、实际账号状态正确；Windows 11 另行验证。
2. 有记录好友/群聊出现，备注和昵称均可搜；同名好友显示独立 username。
3. 对照微信抽查私聊与群聊跨分片的发送者、时间和顺序；未知身份应明确标记。
4. 导出三种格式和单格式；取消一次长会话，检查汇总、成功会话保留和暂存清理。
5. 本机仍有缓存的图片（含 V2 图片）与普通文件正常导出；缺失缓存明确显示不可用。
6. 切换多账号、中文/空格路径、磁盘根目录来源；验证固定所选账号。
7. EXE 无 Python 环境启动，调整窗口尺寸，搜索选择和导出期间界面保持响应。
8. 任务报错后再导出，重复点击不启动第二任务；关闭窗口等待清理。
