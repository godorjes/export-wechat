# 参考图样式与下拉控件调整

本轮只修改现有 Tkinter 界面、相关回归测试及说明。不新增依赖，沿用白色、浅灰色和微信绿色卡片布局。微信数据读取与导出引擎保持上一版本实现。

## 参考图样式

- 白色页头、绿色双气泡标识和“本地电脑版”标记；检测、真实账号状态及帮助采用圆角按钮和状态胶囊。
- 浅灰蓝背景及左右主卡片；右侧保存格式、导出内容、保存路径分别使用带彩色图标的小卡片、淡色输入区和说明行。
- 左侧聊天使用浅色头像块、细分隔线、好友/群聊标签及浅色时间胶囊；已选择数量的标签随文字长度伸展。
- 底部状态条展示原有账号读取状态和本地引擎提示。软件启动成功后引擎提示可用，账号绿色状态仍以实际数据读取成功为准。
- 默认窗口 1280×820，保留最小 980×640；小窗口可以滚动，卡片随提示换行增高，装饰图标不进入 Tab 顺序。
- 绿色原生标题栏使用 Windows 支持的 DWM 窗口着色；不支持该能力的系统保留原生标题栏，不修改系统全局配色。

此次仅调整样式，没有增加操作入口，没有写入截图中的示例聊天、路径或成功状态。默认仍选 TXT、仅聊天文字。

## 当前界面行为

1. 修复右侧导出设置空白。已复现 Windows 上滚动区域在隐藏滚动条时，设置画布一并未显示的问题；将滚动条布局调整延后到当前布局完成后执行。格式、内容和路径设置从程序启动起就可见，勾选聊天后即可修改，无需先点击导出。窗口缩放、键盘 Tab 和小窗口滚动继续可用。
2. 右上角按钮与状态文字同步。未识别时可点击“检测微信账号”；检测过程中按钮和旁边文字均显示“检测中…”，按钮禁止重复点击；读取成功后显示“重新检测”和“已识别微信账号”。圆点只在真实账号数据读取成功后变绿，代表数据可读取，不把目录或进程当作登录证明。失败时恢复可检测状态，并在原状态区显示原因。
3. “保存格式”使用下拉框内多选。默认 TXT，展开后可连续勾选 TXT、Markdown、JSON，收起后显示已选格式；全部取消时提示至少选择一种格式并禁用导出。保存格式、导出内容和好友/群聊筛选共用 42px 圆角输入区、统一箭头、40px 弹出选项行、绿色选中态及浅色悬停效果。支持鼠标、方向键、空格、Enter、Escape 和 Tab；外部点击、失焦、窗口移动缩放、控件禁用时关闭弹出列表。
4. 删除“更多选项”、导出预览及“查看任务详情”的入口和隐藏弹窗。导出完成后仅保留“打开文件夹”，失败原因及清理警告显示在原有任务状态区。左侧筛选、搜索、勾选、全选当前列表和已选数量保持不变。

## 保留之前已确认的行为

- “保存到哪里”仅保留可编辑路径和 Windows 原生文件夹选择按钮，默认路径沿用此前版本。导出前先校验目录可创建、可写。
- 导出期间显示“导出中…”或取消状态，不显示虚假百分比、进度条或 0/0 计数。
- 导出文件直接放入 yyyy-MM-ddWeChatExport 目录，以电脑本地日期命名；同一天复用该目录，不生成 task_index、INCOMPLETE 等任务文件。
- 重名、重复导出和多个程序同时导出会协调编号，不覆盖既有记录；取消或失败时回收当前未完成文件，保留已完成聊天。

~~~text
选定的保存位置/
└─ 2026-10-15WeChatExport/
   ├─ 小林.txt
   ├─ 小林.json           # 同时勾选 JSON 时
   ├─ 家人群.txt
   ├─ 家人群.json
   └─ 小林_media/         # 启用附件且存在可导出的缓存时
      ├─ images/
      └─ files/
~~~
