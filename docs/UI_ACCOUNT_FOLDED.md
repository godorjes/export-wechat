# 界面精简与设置区显示修复（本地版）

本轮只修改现有 Tkinter 界面、相关回归测试及说明。不新增依赖，沿用白色、浅灰色和微信绿色卡片布局。微信数据读取与导出引擎保持上一版本地实现，不提交或推送 Git。

## 本轮四项调整

1. 修复右侧导出设置空白。已复现 Windows 上滚动区域在隐藏滚动条时，设置画布一并未显示的问题；将滚动条布局调整延后到当前布局完成后执行。格式、内容和路径设置从程序启动起就可见，勾选聊天后即可修改，无需先点击导出。窗口缩放、键盘 Tab 和小窗口滚动继续可用。
2. 右上角按钮与状态文字同步。未识别时可点击“检测微信账号”；检测过程中按钮和旁边文字均显示“检测中…”，按钮禁止重复点击；读取成功后显示“重新检测”和“已识别微信账号”。圆点只在真实账号数据读取成功后变绿，代表数据可读取，不把目录或进程当作登录证明。失败时恢复可检测状态，并在原状态区显示原因。
3. “保存格式”改为主区域复选框。TXT、Markdown、JSON 可直接多选，默认勾选 TXT；全部取消时提示至少选择一种格式并禁用导出。删除整个“更多选项”区域，包括重复格式入口、完成后自动打开文件夹、导出全部聊天及重复任务详情入口。左侧筛选、搜索、勾选、全选当前列表和已选数量保持不变。
4. 删除新版界面的全部导出预览入口、关联回调和导入。导出完成后仅保留“打开文件夹”。底部任务状态、取消导出和“查看任务详情”继续保留，供查看实际日志及失败原因。

## 保留之前已确认的行为

- “保存到哪里”仅保留可编辑路径和 Windows 原生文件夹选择按钮，默认路径沿用此前版本。导出前先校验目录可创建、可写。
- 导出期间显示“导出中…”或取消状态，不显示虚假百分比、进度条或 0/0 计数。
- 导出文件直接放入 yyyy-MM-ddWeChatExport 目录，以电脑本地日期命名；同一天复用该目录，不生成 task_index、INCOMPLETE 等任务文件。
- 重名、重复导出和多个程序同时导出会协调编号，不覆盖既有记录；取消或失败时回收当前未完成文件，保留已完成聊天。

~~~text
选定的保存位置/
└─ 2026-10-15WeChatExport/
   ├─ 小林.txt
   ├─ 小林.json           # 同时勾选 JSON 时
   ├─ 家人群.txt
   ├─ 家人群.json
   └─ 小林_media/         # 启用附件且存在可导出的缓存时
      ├─ images/
      └─ files/
~~~
