# Windows 微信导出 V1.0 Implementation Plan

> For agentic workers: Use superpowers:executing-plans to implement this plan task-by-task. 用户已要求直接编码、测试、构建并推送；本次在指定上游源码的独立 checkout 中连续执行。

**Goal:** 加载可靠本地好友/群聊，以 username 多选后按所选格式稳定批量导出。

**Architecture:** 复用上游核心和敏感沙箱，服务层负责元数据与任务，ttk 负责展示。数据库上下文仅在后台操作期间存在；每个批次复用一个实例，退出时清理。

**Tech Stack:** Python 3.12、Tkinter/ttk、threading/queue、SQLite、wechatauto-replica==1.2.4.4、PyInstaller。

**Spec:** `docs/V1_TASK.md`；源码核对见 `docs/CODE_AUDIT.md`。

## Global Constraints

- Windows 10 64 位，兼容 Windows 11；微信版本：4.1.15.13。
- 不新增数据库解密、进程注入或密钥提取；原始微信数据库只读。
- 用户只选一种格式时不写其他聊天格式；任务汇总独立于聊天格式。
- 不扫描消息正文来展示列表；未知身份统计并跳过。
- 不联网或上传聊天；日志不包含消息正文、数据库密钥。
- GUI 线程只消费队列；不能重复启动冲突任务；取消和异常必须清理。
- 原版接口、许可证与成熟媒体逻辑保留。

## Review Focus

- 中文、空格和磁盘根路径：目录规范化与合成目录测试。
- 同名会话、不同账号切换：username 选择和更换源清空选择测试。
- 会话中途取消：无最终半成品、已有成功结果保留，沙箱恢复测试。
- 不可写目录、未知/过期 username：明确错误并能再次启动测试。
- 仅 TXT/MD 与大量预览：无隐式 JSON、固定页大小与控件释放 GUI 测试。
